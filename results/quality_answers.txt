ANSWER:
Scaled dot‑product attention is a way to compute attention weights using the dot product of a query with each key.  
1. For each query vector **q** and each key vector **k**, compute the dot product **q·k**.  
2. Divide each dot product by the square root of the key dimension \( \sqrt{d_k} \) to keep the values in a reasonable range.  
3. Apply a softmax to these scaled scores to get a probability distribution over the keys.  
4. Use this distribution to weight the corresponding value vectors **v** and sum them to produce the output.  

Mathematically:  

\[
\text{Attention}(Q,K,V)=\text{softmax}\!\left(\frac{QK^{\top}}{\sqrt{d_k}}\right)V
\]

This is the attention function used in the Transformer paper (Ashish Vaswani et al., “Attention Is All You Need”, arXiv:1706.03762 v7, p. 4).

ANSWER:
The division by √dₖ (the key dimension) is a *scaling factor* that keeps the dot‑product values in a reasonable range before the softmax is applied.  
When the query and key vectors are of high dimensionality, their dot product can grow large in magnitude. A large pre‑softmax score pushes the softmax toward a very “peaked” distribution, which can make learning difficult and reduce the effective gradient. By dividing by √dₖ the authors of the original Transformer paper ensured that the typical magnitude of the scores remains close to 1, keeping the softmax well‑behaved and improving training stability (see “Scaled Dot‑Product Attention” in *Attention Is All You Need*, arXiv:1706.03762 v7, PDF page 4).

Multi‑head attention is a way of running several attention mechanisms in parallel so that the model can focus on different parts of the input at the same time. For each of the \(h\) heads we linearly project the queries, keys and values with separate matrices \(W_Q^i,\,W_K^i,\,W_V^i\), compute scaled dot‑product attention, and obtain a head output \(\text{head}_i = \text{Attention}(QW_Q^i,\,KW_K^i,\,VW_V^i)\). The \(h\) head outputs are then concatenated and projected again with \(W_O\) to produce the final result:

\[
\text{MultiHead}(Q,K,V)=\text{Concat(head}_1,\dots,\text{head}_h)W_O .
\]

Recurrent neural networks, long short-term memory [13] and gated recurrent [7] neural networks
in particular, have been firmly established as state of the art approaches in sequence modeling and
transduction problems such as language modeling and machine translation [ 35, 2, 5]. Numerous
efforts have since continued to push the boundaries of recurrent language models and encoder-decoder
architectures [38, 24, 15].

sequences. Aligning the positions to steps in computation time, they generate a sequence of hidden

sequential nature precludes parallelization within training examples, which becomes critical at longer
sequence lengths, as memory constraints limit batching across examples. Recent work has achieved
significant improvements in computational efficiency through factorization tricks [21] and conditional
computation [32], while also improving model performance in case of the latter. The fundamental
constraint of sequential computation, however, remains.

ANSWER:
The Transformer uses self‑attention so that every token in a sequence can look directly at every other token at the same time.  
With self‑attention, a layer computes, for each position, a weighted sum of all positions (using the token’s own query against all keys). This lets the model capture long‑range dependencies without the slow, step‑by‑step recurrence that RNNs use. Because each attention head can focus on different aspects of the input, the model can combine many views of the sequence in parallel, enabling efficient training and better handling of long sentences.
